Welcome to the Mario Kart 8 API


The Mario Kart 8 API is an unofficial, open-source utility that provides access to various data and resources related to the popular racing game, Mario Kart 8.

The MK8 API contains all driver, kart, tire, and glider stats, including speed, acceleration, weight, handling, traction, and mini-turbo

About the API


The MK8 Api is designed to provide developers and enthusiasts with easy access to the game's build stats, allowing them to create their own applications, websites, or tools that utilize this information.

One primary example example of this would be the build calculator, which allows users to input their desired character, kart, tire, and glider combination and receive the resulting stats for that build. This can be useful for players who want to optimize their builds for specific tracks or playstyles.
